# EIDU School AI – clickable prototype

A mobile prototype of the EIDU School app for Kenyan teachers. It covers classes, Tayari and KPLP lesson plans, an AI teaching assistant with live web search, and lesson recording that gives feedback on what the teacher actually said.

- **Open it:** use the GitHub Pages link for this repository (made for phones; on a laptop it shows in a phone frame).
- **AI answers:** this file contains no API key. Testers open the shared link, which carries the key after `#`. The page saves it on that phone and removes it from the address bar. Without it, the Assistant gives demo answers.
- **Microphone:** Chrome asks for the microphone on the first tap. The microphone only works on `https://` pages like the Pages link, not on copies opened from WhatsApp or Downloads.
- **Privacy:** while recording, Chrome's speech recognition turns speech into text. The text, not the audio, is sent to the AI for feedback. No audio is saved.
- **Research report:** `research-report.html` is the Kepler (AI assistant) research report from teacher testing on 18, 19 and 23 Nov 2026. Open it at the Pages link with `/research-report.html` on the end.

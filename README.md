# EIDU School AI – clickable prototype

A mobile prototype of the EIDU School app for Kenyan teachers. It covers classes, Tayari and KPLP lesson plans, lesson recording feedback, and an AI teaching assistant that can answer with live web search.

- **Open it:** use the GitHub Pages link for this repository (made for phones; on a laptop it shows in a phone frame).
- **AI answers:** this file contains no API key. Testers open the shared link, which carries the key after `#`. The page saves it on that phone and removes it from the address bar. Without it, the Assistant gives demo answers.
- **Microphone on phones:** Chrome only allows the microphone on pages opened from an `https://` link, such as the Pages link. A copy opened from WhatsApp or Downloads can't record voice questions.
